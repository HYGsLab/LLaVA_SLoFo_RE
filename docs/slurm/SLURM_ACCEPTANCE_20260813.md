# Slurm 迁移与运行验收记录（2026-08-13）

## 验收结论

LLaVA-1.5-7B + SLoFo/Focus 项目已经可以在 Slurm 的 RTX 4090 上继续开发与实验。代码、固定版本环境、完整模型权重、此前使用的 1624 题 benchmark 固定子集、Slurm 作业模板和独立结果目录均已建立。

## 资源与隔离

- 项目目录权限：个人目录，未访问他人项目内容；
- 当前占用：项目约 15 GiB，环境约 3.4 GiB，结果约 19 MiB；
- 共享 NFS：约 212 TiB 可用；
- 他人/老师学生作业 2611（gn3）全程未操作；
- 所有验收作业只允许 gn4/gn5/gn6/gn8，并在模型加载前验证实际 GPU 显存为空。

## 功能验收

1. 基础 LLaVA：视觉塔输出 `(1, 576, 1024)`，投影后 `(1, 576, 4096)`，完整多模态输入 `(1, 630, 4096)`。
2. Scan-Locate：捕获第 14 层规划注意力和第 7 层结构隐藏态，成功生成语义/结构/SSIM 显著图和裁切框。
3. Focus：三阶段原图 Token 计划为 `576→288→144→72`，并完成原图、裁切、双图、Focus 四条回答链路。
4. FP32 语义显著性修正：FP16 非零值 39/576，转 FP32 计算后 576/576，说明此前数量级问题已规避。
5. 批处理：模型一次加载后能按 manifest 逐题运行，输出 `batch_summary.json`、`benchmark_answers.jsonl` 与完整案例可视化。
